# 在你的电脑上安装 dsh-fleet-feishu（飞书飞派）

> 一句话：**设置 → Plugins → 装市场 bundle → 填一行索引地址 → 就能在 Discover 页看见它并一键安装/升级**。

---

## 一、前提（缺一不可）

| 项 | 说明 | 怎么查 |
|---|---|---|
| DSH 桌面客户端 | 0.2.2-rc.1 或更高 | 客户端 → 关于 |
| 飞书自建应用（机器人） | 已把 bot 拉进群 | 群成员里能看到它 |
| lark-cli | `npm i -g @larksuite/cli` | `lark-cli --version` |
| 能出网到 GitHub | 拉插件用 | `git clone https://github.com/hongwanemail/dsh-fleet-feishu` |

---

## 二、三步安装

### 第 1 步：装"插件市场"这个官方 bundle

它提供 Discover 页（浏览/安装/升级插件）。

**版本必须与你的 DSH 完全一致**，否则 DSH 会拒绝加载并报 `incompatible with dsh <你的版本>`。

```powershell
# 查你的 DSH 版本
dsh --version
# 然后装【同版本】的市场 bundle（把 0.2.2-rc.1 换成你的版本号）
dsh plugin --profile desktop add '@deepseek-ai/dsh-experimental-plugin-market-bundle@0.2.2-rc.1'
```

> ⚠️ **坑**：直接 `add` 不带版本号会装 npm 上的 latest（可能是 alpha 版），**版本对不上就会被 DSH 禁用**。
> 一定要带 `@<你的 DSH 版本>`。

### 第 2 步：配一行索引地址

编辑 `~/.dsh/profiles/desktop/cordis.patch.yml`，**追加**（不要删已有内容）：

```yaml
- id: plugin-market
  config:
    indexes:
      - https://fastly.jsdelivr.net/gh/hongwanemail/dsh-fleet-feishu@master/market-index.json
```

> ⚠️ **坑 1**：这个文件是**顶层 YAML 数组**。如果文件里只有一个 `[]`（空数组占位），要**把它替换掉**再追加上面这段 —— 否则会出现两个数组，DSH 报 `parsePatchList` 错误。
> ⚠️ **坑 2**：缩进必须是 2 空格（`config:`）和 4 空格（`indexes:`），列表项 6 空格。

### 第 3 步：重启客户端

关掉再打开 DSH → 侧栏 **Discover** 页 → 应该能看到「飞书飞派 · 多设备 agent 调度」→ 点安装。

---

## 三、安装后填两项配置

在插件设置里填（或改 `cordis.patch.yml` 的 `fleet-feishu` 行）：

```yaml
- id: fleet-feishu
  config:
    device_name: 我的机器名        # 群里署名，如「小鲸鱼-办公室PC」
    chat_id: oc_xxxxxxxxxxxx      # 群 ID（群设置里能看到）
```

**`bot_open_id` 不用填** —— 插件会拉群名册、用自己的 app_id 自动匹配出来。

---

## 四、验证

在飞书群里发：

```
@你的bot /status
```

收到状态卡 = 装好了。

再派个活试试（会先问「在吗」）：
```
@你的bot 帮我看一下今天的待办
```

---

## 五、以后怎么升级

**有市场索引后**，客户端 Discover 页会显示新版本 → 点「更新」即可（`updateBundle` 会按索引里钉的 commit 重装）。

**手动升级**（不走市场）：
```powershell
dsh plugin --profile desktop remove dsh-fleet-feishu
dsh plugin --profile desktop add github:hongwanemail/dsh-fleet-feishu
```

## 六、常见问题

| 现象 | 原因 | 解法 |
|---|---|---|
| `incompatible with dsh x.y.z` | 市场 bundle 版本与 DSH 不匹配 | 装 `@<你的 DSH 版本>` |
| `parsePatchList` 报错 | cordis.patch.yml 里同时有 `[]` 和新条目 | 删掉 `[]` 那行 |
| Discover 页空白 | 索引 URL 拉不到 | 浏览器打开那个 raw 链接，能出 JSON 即可 |
| 插件装了但群里 @ 没反应 | bot 没被 @ 到 / chat_id 填错 | `/status` 看状态卡 |
| 拉 GitHub 超时 | 网络出网受限 | 见下「内网机器」 |

### 内网机器（拉不到 GitHub）

客户端出网受限的机器装不了 git 源插件。两个办法：
1. 让能上网的机器 `pnpm pack` 出 tarball，拷过去 `dsh plugin add ./x.tgz`
2. 直接把插件源码目录放到本机，`dsh plugin add <本地目录>`（link 源，版本会显示"可更新"提示，属正常）
